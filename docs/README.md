# Документация vtx2exl

vtx2exl переносит моды Cyberpunk 2077 из Vortex или Mod Organizer 2 в сборку ExLauncher. Только Windows. Пользовательское описание лежит в корневом `README.md`, здесь то, что нужно тому, кто будет это чинить и развивать.

Поддержка MO2 написана по исходникам MO2 и проверена на синтетических каталогах (`tests/mo2.mjs`). На настоящей установке MO2 она не запускалась. Подробнее в `MAINTAINING.md`, раздел "Что не проверено".

## Карта репозитория

```
src/vtx2exl.cpp     ядро: весь перенос, откат, очистка, самопроверка
src/crc32c.asm      аппаратный crc32c
src/events.txt      описание JSON-протокола ядра (одна страница, это спецификация)
ui/                 терминальный интерфейс (Bun + Ink), собирается в VTX2EXL-UI.exe
analyzer/           разбор конфликтов внутри сборки или профиля MO2 (Node/Bun, без зависимостей)
proto/whales        анимация китов на главном экране
proto/graph         граф и экран проблем на карте конфликтов
tests/mo2.mjs       интеграционный тест ядра на сгенерированном каталоге MO2
.github/workflows   CI и черновик релиза
docs/               эти файлы
```

Каталоги `menu/` и `vtx2exl-menu.cmd` в git не входят. Это старое меню, в сборку и тесты оно не участвует.

## Что должно быть установлено

Visual Studio 2022 (ml64 и cl), Bun 1.3.x, Node.js. Для разбора архивов анализатору нужен csc.exe из .NET Framework 4 (есть в Windows) и `oo2ext_7_win64.dll` из папки игры.

## Три правила, которые стоит запомнить сразу

1. Тестовые прогоны `--apply` делай только на временных каталогах. Игру, ExLauncher и реальные папки модов не трогай.
2. Ядро и анализатор независимо читают одни и те же форматы (ini Qt, modlist.txt, архивы). Правишь разбор в одном, проверь второй. Список парных мест в `ARCHITECTURE.md`, раздел "Дублирование логики".
3. После правки `src/vtx2exl.cpp` корневой `vtx2exl.exe` сам не обновится: `ui\build.cmd` собирает ядро только если файла нет.
